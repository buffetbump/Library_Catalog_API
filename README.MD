# Каталог книг библиотеки (Library Catalog API)

Асинхронное веб-приложение для автоматизированного учета и обогащения данных книг.

## 🛠 Технологический стек
- **FastAPI** — асинхронный веб-фреймворк
- **SQLAlchemy 2.0 & asyncpg** — ORM для работы с базой данных в асинхронном режиме
- **PostgreSQL** — надежное хранилище данных
- **Alembic** — управление миграциями базы данных
- **Pydantic v2** — строгое валидирование входных и выходных данных
- **HTTPX** — асинхронный клиент для интеграции с Open Library API
- **Poetry** — менеджер зависимостей и виртуального окружения

## 🚀 Инструкция по локальному запуску

1. **Установка зависимостей проекта:**
   ```bash
   poetry install
   ```

2. **Запуск базы данных PostgreSQL в фоне:**
   ```bash
   docker-compose up -d postgres
   ```

3. **Применение миграций базы данных:**
   ```bash
   poetry run alembic upgrade head
   ```

4. **Запуск локального веб-сервера:**
   ```bash
   poetry run python -m library_catalog.main
   ```

После запуска интерактивная документация со всеми эндпоинтами доступна по адресу:  
👉 **http://localhost:8000/docs**
